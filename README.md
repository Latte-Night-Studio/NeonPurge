# NEON PURGE

Аркадний шутер з видом зверху, повністю написаний на Rust. Рендер повністю
програмний: гра малює кожен піксель у власний буфер, тому окрім віконного
крейта `minifb` жодних залежностей немає — ні ігрових рушіїв, ні графічних
ресурсів.

## Готова гра (без Rust)

`NeonPurge.exe` — самодостатній файл для Windows x64: нічого встановлювати не
треба, жодних DLL чи ресурсів поруч. Достатньо скопіювати його на будь-який
комп'ютер і запустити подвійним кліком. Рекорд зберігається в
`neon_purge_highscore.txt` у тій самій папці.

`NeonPurge-win64.zip` — той самий exe разом із цим README, якщо зручніше
передати одним архівом.

Файл не підписаний цифровим сертифікатом, тож Windows SmartScreen може
показати «Windows захистив ваш ПК» — тисніть **Додаткові відомості → Виконати
все одно**. Це нормально для саморобних програм без підпису.

## Як грати

| Дія | Клавіша |
| --- | --- |
| Рух | `W A S D` або стрілки |
| Приціл | миша |
| Стрільба | ліва кнопка миші |
| Ривок (невразливість) | `Shift` / `Space` |
| Перезарядка | `R` |
| Змінити зброю | `Q` |
| Пауза | `P` / `Esc` |
| Старт / рестарт | `Enter` / `Space` / `R` |

Мета — протриматися якнайдовше. Хвилі ворогів стають складнішими: з'являються
швидкі «бігуни», стрільці та важкі танки. Після зачистки хвилі гравець
отримує бонус і трохи здоров'я. З ворогів випадають аптечки та набої.
Серії вбивств без поранень підвищують множник очок (до x5).

## Зброя

- **RIFLE** — автоматична, 30 набоїв, точна, швидка перезарядка.
- **SHOTGUN** — 6 набоїв, 9 дробин за постріл, сильний відкид, добрий на близькій дистанції.

## Запуск

```powershell
cargo run --release
```

Перша збірка завантажить і скомпілює `minifb` (кілька десятків секунд).

Перевірка без вікна (логіка + рендер проганяються 2700 кадрів):

```powershell
cargo run --release -- --smoke
```

## Налаштування інструментів на цій машині

Rust не був встановлений, тому він поставлений через `winget`
(`Rustlang.Rustup`). Оскільки Visual Studio C++ Build Tools відсутні, проєкт
використовує GNU-ціль та компілятор MinGW-w64 (WinLibs), який лежить у
`C:\Users\Sunny\Tools\mingw64`. Шлях до лінкера прописаний у
`.cargo/config.toml`, тому `cargo build` / `cargo run` працюють без
додаткових налаштувань. Якщо перенести MinGW в інше місце — оновіть
`linker` у цьому файлі.

Типовою для `rustup` зроблена GNU-збірка інструментів, бо build-скрипти
залежностей теж компілюються GCC:

```powershell
rustup toolchain install stable-x86_64-pc-windows-gnu
rustup default stable-x86_64-pc-windows-gnu
```


## Структура

```
src/
  main.rs        цикл вікна, ввід, headless smoke-тест
  math.rs        Vec2 та базова векторна математика
  canvas.rs      програмний растеризатор (кола, полігони, текст, glow)
  font.rs        власний бітмап-шрифт 5x7
  game/
    mod.rs       стан гри, гравець, зброя, хвилі, ефекти
    sim.rs       вороги, кулі, підбори, зіткнення, смерть
    draw.rs      світ, HUD, меню, фон
```

Рекорд зберігається поруч з виконуваним файлом у
`neon_purge_highscore.txt`.
