# NEON PURGE

Аркадний шутер з видом зверху, написаний повністю на Rust. Рендер програмний:
гра сама малює кожен піксель у власний буфер, тому жодних ігрових рушіїв,
OpenGL/DirectX, текстур чи інших асетів немає. Єдина залежність — крейт
[`minifb`](https://crates.io/crates/minifb) для створення вікна.

Тримайтеся якнайдовше, знищуйте хвилі ворогів, збирайте аптечки та набої й
полюйте за рекордом.

## Завантаження

Готовий білд для Windows x64 лежить у розділі
**[Releases](https://github.com/Latte-Night-Studio/NeonPurge/releases/latest)**:

| Файл | Що це |
| --- | --- |
| **[NeonPurge.exe](https://github.com/Latte-Night-Studio/NeonPurge/releases/latest/download/NeonPurge.exe)** | Самодостатній exe. Запускається подвійним кліком. |
| **[NeonPurge-win64.zip](https://github.com/Latte-Night-Studio/NeonPurge/releases/latest/download/NeonPurge-win64.zip)** | Той самий exe разом із цим README. |

Встановлювати Rust, DLL чи VC++ Redistributable не потрібно. Просто скопіюйте
файл на будь-який комп'ютер із Windows x64 і запустіть.

Гра відкриває лише своє вікно: чорне вікно консолі не з'являється, бо release-білд
зібраний як GUI-програма (`windows_subsystem = "windows"`).

> Файл не підписаний цифровим сертифікатом, тому Windows SmartScreen може
> показати «Windows захистив ваш ПК». Натисніть **Додаткові відомості →
> Виконати все одно** — це нормально для невеликих відкритих проєктів без
> платного підпису.

Рекорд зберігається поруч з exe у файлі `neon_purge_highscore.txt`, а
налаштування — у `neon_purge_settings.txt`.

## Android-версія

Та сама гра доступна на Android як нативний APK: ті самі хвилі, зброя, меню й
локалізація, але з дотиковим керуванням, повноекранним рендером і звуком через
AAudio. Потрібен **Android 8.0+**.

| Файл | Що це |
| --- | --- |
| **[NeonPurge-android-1.4.0.apk](https://github.com/Latte-Night-Studio/NeonPurge/releases/download/v1.4.0-android/NeonPurge-android-1.4.0.apk)** | Підписаний APK для Android 8.0+ |

Коротко про керування: ліва половина екрана — рух, права — приціл і
автоматичний вогонь, зверху — слоти зброї `1`–`9`, праворуч — **RELOAD**,
**DASH**, **SWAP** і **PAUSE**. Докладніше — у
[`neonpurgeandroid/README.md`](neonpurgeandroid/README.md): встановлення,
керування, збірка APK, підпис і архітектура порту.

Десктопна версія не змінилася: Android-порт повторно використовує той самий код
гри через окремий crate `neonpurgeandroid`.

## Керування

Меню працюють мишею: наведіть курсор на кнопку й натисніть ліву кнопку.
Клавіатура теж підтримується (`Enter`, `Esc`, `P`, `R`).

| Дія | Клавіша |
| --- | --- |
| Рух | `W A S D` або стрілки |
| Приціл | миша |
| Стрільба | ліва кнопка миші |
| Ривок (коротка невразливість) | `Shift` або `Space` |
| Перезарядка | `R` |
| Вибір зброї | `1`–`9` (або цифри на блоці `NumPad`) |
| Наступна зброя | `Q` |
| Пауза | `P` або `Esc` |
| Звук увімкнути / вимкнути | `M` |
| Старт / рестарт | `Enter`, `Space` або `R` |

## Налаштування

Кнопка **НАЛАШТУВАННЯ** є на головному екрані, у паузі та на екрані поразки.
Там можна змінити:

- **Режим вікна** — віконний, без рамки або повноекранний;
- **Роздільна здатність** — 1280×720, 1600×900, 1920×1080, 2560×1440 або
  3840×2160;
- **Мову** — українська або англійська (увесь інтерфейс, HUD і підказки);
- **Звук** — увімкнено або вимкнено.

Вибір одразу застосовується та зберігається у `neon_purge_settings.txt` поруч
з exe, тому наступний запуск відкриється в тих самих режимі, роздільній
здатності та мові. Типові значення: віконний режим, 1280×720, українська мова,
звук увімкнено.

Роздільна здатність задає розмір вікна у віконному та безрамковому режимах.
Якщо вибране вікно більше за робочий стіл, воно пропорційно зменшується, щоб
повністю вміститися на екрані. Повноекранний режим завжди використовує повну
роздільну здатність поточного монітора: буфер 1280×720 масштабується на весь
екран із збереженням пропорцій, а вікно тримається поверх панелі завдань та
інших вікон — рамки, заголовка чи панелі завдань не видно. Режим без рамки —
це вікно обраного розміру без заголовка й кнопок, по центру екрана. Повернутися
до віконного режиму можна через те саме меню налаштувань.

## Звук

Увесь звук синтезується в коді під час запуску гри: жодних mp3/wav-файлів,
семплів чи додаткових аудіо-бібліотек. Короткі ефекти генеруються процедурно,
змішуються у фоновий стереопотік і виводяться через системний `waveOut` на
Windows. Панорама залежить від позиції події, а гучність — від відстані.

Озвучено всі дев'ять видів зброї (пістолет, кулемет-пістолет, дробовик,
гвинтівка, снайперка, кулемет, ракета, граната, ніж), вибухи, влучання, смерть
ворогів, тихе вбивство, вибух танка, поранення гравця, ривок, перезарядку, зміну
зброї, підбори, початок хвилі, зачистку хвилі, постріли ворогів, старт, поразку
та елементи меню. Клавіша `M` вимикає або вмикає звук; у HUD з'являється
позначка `SOUND OFF`.

Перевірити звукову карту й почути всі ефекти по черзі можна так:

```powershell
cargo run --release -- --audio-test
```

## Геймплей

- **Хвилі.** Кожна наступна хвиля більша й небезпечніша. Після зачистки дають
  бонус до очок і +18 HP, а через кілька секунд починається нова хвиля.
- **Вороги.** Звичайні `GRUNT`, швидкі `RUNNER` (з 2-ї хвилі), стрільці
  `SHOOTER` (з 3-ї) та важкі `TANK` (з 5-ї). Кожні п'ять хвиль — елітна.
- **Дроп.** З ворогів випадають аптечки (+30 HP) та набої.
- **Комбо.** Серія вбивств без поранень підвищує множник очок до **×5**.
  Отримали урон — комбо скидається.
- **Ривок.** Дає кілька кадрів невразливості; допомагає вирватися з натовпу.
- **Помітність.** Вороги починають хвилю неуважними: патрулюють, мають конус
  зору й позначаються знаком `?`, поки не помітять гравця. Постріли, вибухи та
  загибель товаришів будять усіх у радіусі шуму. Ніж убиває неуважного ворога
  миттєво й тихо — без тривоги та з **×1.5** очок за «тихе вбивство».

## Зброя

Усі дев'ять категорій доступні одразу: оберіть слот цифрою `1`–`9` або
гортайте `Q`. Стартова зброя — штурмова гвинтівка (слот `4`). Кожна категорія
має власну роль, темп, магазин, урон і гучність; важка зброя сповільнює рух,
ніж навпаки дає прискорення.

| № | Зброя | Магазин | Перезарядка | Роль і особливості |
| --- | --- | --- | --- | --- |
| 1 | **PISTOL** | 12 | 0.75 с | Точний напів-автомат, 24 урону, дешевий і швидкий перезаряд |
| 2 | **SMG** | 36 | 1.25 с | Автоматичний вогонь, 9 урону за кулю, розсіювання на середній дистанції |
| 3 | **SHOTGUN** | 6 | 1.75 с | 9 дробин × 11 урону, сильний відкид, для ближнього бою |
| 4 | **ASSAULT RIFLE** | 30 | 1.05 с | Універсальний автомат, 14 урону, точніший за SMG |
| 5 | **SNIPER RIFLE** | 5 | 2.2 с | 95 урону, пробиває до 4 ворогів у лінію, повільний темп |
| 6 | **MACHINE GUN** | 100 | 4.5 с | 100 патронів безперервного вогню, 11 урону, помітне сповільнення |
| 7 | **ROCKET LAUNCHER** | 3 | 2.8 с | Ракета з вибухом (105 урону, радіус 120), найсильніше сповільнення |
| 8 | **GRENADES** | 4 | 2.3 с | Граната з відскоком і детонатором (88 урону, радіус 150) |
| 9 | **KNIFE** | — | — | Без набоїв, 58 урону по готовому ворогу; тихо вбиває неуважних |

### Тихий ніж

Ніж не витрачає набоїв і не створює шуму. Якщо ворог ще не помітив гравця і
перебуває в радіусі удару, він гине миттєво: інші вороги не чують пострілу,
а на екрані з'являється напис `SILENT KILL` (українською — `ТИХЕ ВБИВСТВО`).
Уже розлючений ворог отримує лише 58 урону, тож ніж — це інструмент
непомітного підходу, а не заміна автомата в відкритому бою.

## Збірка з джерел

Потрібен стабільний Rust (2021 edition) і компонувальник для вашої платформи:
MSVC Build Tools на Windows або GCC/MinGW для GNU-цілі.

```powershell
cargo run --release
```

Перша збірка завантажить і скомпілює `minifb`, тому може зайняти кілька
десятків секунд.

Перевірка без вікна — логіка та рендер проганяються 2700 кадрів:

```powershell
cargo run --release -- --smoke
```

Готовий exe з'явиться у `target/release/neon-purge.exe` (або в
`target/x86_64-pc-windows-gnu/release/`, якщо увімкнено GNU-ціль).

У release-збірці консольного вікна немає. Режими `--smoke` та `--audio-test`
самі під'єднуються до термінала, з якого їх запущено, тому їхній вивід видно
як звичайно.

## Структура

```
src/
  main.rs        цикл вікна, ввід, headless smoke-тест
  audio.rs       процедурний синтез звуку та мікшер waveOut
  math.rs        Vec2 та базова векторна математика
  canvas.rs      програмний растеризатор (кола, полігони, текст, glow)
  font.rs        власний бітмап-шрифт 5x7 (латиниця й кирилиця)
  lang.rs        словники інтерфейсу: українська та англійська
  settings.rs    збереження режиму вікна, роздільної здатності, мови та звуку
  storage.rs     шляхи до файлів налаштувань і рекорду
  ui.rs          геометрія кнопок меню та hit-testing
  platform.rs    Win32: розмір вікна, без рамки й повноекранний режим
  game/
    mod.rs       стан гри, гравець, зброя, хвилі, ефекти, меню
    sim.rs       вороги, кулі, снаряди, вибухи, підбори, зіткнення, смерть
    draw.rs      світ, HUD, меню, фон
```

## Технічні деталі

- Лише одна зовнішня залежність — `minifb`; звук працює через системний
  `winmm`, без аудіо-крейтів.
- Віконний, безрамковий і повноекранний режими та роздільна здатність
  перемикаються через Win32 API (`user32`) напряму, тому нових залежностей
  немає.
- Вікно створюється одразу потрібного розміру: `minifb` дізнається про зміну
  розміру лише з `WM_SIZE`, тому пізнє розтягування залишало буфер 1280×720
  намальованим 1:1 у куті екрана.
- Меню малюються тим самим софтверним рендерером; кнопки підсвічуються при
  наведенні та «просідають» при натисканні.
- Дев'ять категорій зброї описані даними (темп, магазин, урон, розсіювання,
  снаряди, гучність, штраф до руху), тому HUD і баланс змінюються в одному місці.
- Вороги мають стан помітності: конус зору, патрулювання, поширення тривоги від
  шуму та миттєву смерть від ножа, поки гравець не виявлений.
- Інтерфейс локалізовано українською та англійською; кириличні гліфи вбудовані
  у власний шрифт 5×7.
- Власний софтверний рендерер: геометрія, glow, частки, тряска екрана.
- Процедурний синтезатор і стереомікшер: 44.1 кГц, 16 біт, панорама й
  затухання за відстанню.
- Фіксований ігровий крок із hit-stop та плавним рендером.
- Детермінований xorshift-генератор випадкових чисел.
- Release-білд компонується як GUI-програма — без окремого вікна консолі;
  критичні помилки старту показуються в діалозі Windows.
- `--smoke` запускає гру без вікна й перевіряє, що симуляція, рендер і
  генерація звукових подій працюють коректно.
- `--audio-test` по черзі відтворює всі ефекти для перевірки звуку.
